# 🎂 Age Calculator

A simple and user-friendly **Age Calculator web application** that calculates a person's exact age based on their date of birth.

## 📌 Project Overview

The Age Calculator allows users to select their date of birth and calculate their current age. The result is displayed in **years, months, and days**.

This project was created as a beginner-friendly web development project to practice **HTML, CSS, and JavaScript**.

## ✨ Features

- 📅 Date of birth selection
- 🧮 Automatic age calculation
- 📊 Displays age in years, months, and days
- 🎨 Simple and attractive user interface
- 📱 Easy to use
- ⚡ Instant result without page reload

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page
- **CSS3** – Styling and user interface
- **JavaScript** – Age calculation and functionality
